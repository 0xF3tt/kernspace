    Read the mat.

    The self-healing cutting mat on a designer's desk, printed as a threat model. Pick a line from the key to find its mark on the sheet.

    On the matIn the threat model

      Four inks, three grounds each.

      Each ink comes from the history of print and computing, and each ground is a real material. All twelve are contrast-checked against WCAG and simulated for protan, deutan and tritan vision. Choose one to use it in the studio.

      Cutting Mat is the first series.

      Three more are drawn in pencil and waiting for press. Each borrows a layout from graphic design and gives every element on it a security meaning.

      Cutting Mat Live

      A designer's cutting mat, read as a threat model: rulers, a taint path, trust boundaries and tape.

      The self-healing mat on every design desk.

      Specimen Concept

      A foundry type specimen. The field's core primitive is set as a typeface, with the one unhandled case left as an empty box.

      Caslon's specimen broadside, 1734.

      Galley Proof Concept

      Security review as proofreading. Each finding gets the proofreader's mark that matches the fix; the advisory is an errata slip.

      Proofreaders' marks, Chicago Manual of Style, 1906.

      Catalog Card Concept

      Every concept catalogued like a book: a call number from a real framework, one typed definition, corrections in pencil.

      Dewey's Library Bureau card, 1876.

      Colophon

      Set in Newsreader and JetBrains Mono. The sheets themselves use Nunito for the phrase and JetBrains Mono for everything else, with ligatures off so code reads as typed.

      No hoodies, no green rain, no padlocks, no skulls.

      How it's made

      Every sheet is drawn as SVG in your browser and turned into a PNG on a canvas. Nothing is uploaded, and no image here comes from an image-generation model.
